    使用说明

    1. 先点“同时打开两边”（或分别打开）。
    2. 再点“复制问题”。
    3. 切到 ChatGPT：粘贴（Cmd/Ctrl+V）→ 回车发送。
    4. 切到 Gemini：粘贴（Cmd/Ctrl+V）→ 回车发送。

    快捷键

    • Cmd/Ctrl + Enter: 复制问题
    • Cmd/Ctrl + Shift + O: 同时打开两边

    说明

    • 不使用 API key，不调用 OpenAI/Google API。
    • 不读取第三方网页 DOM，不自动填充或发送。
    • 不使用 iframe（第三方站点通常会禁止嵌入）。
